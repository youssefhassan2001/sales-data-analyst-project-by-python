# Sales Data Analysis — Python & Excel

## 📌 Project Overview

This project analyzes sales data to identify sales performance, profitability, top-performing products, city performance, and monthly sales trends.

The project follows a complete Data Analyst workflow:

**Data Cleaning → Exploratory Data Analysis → KPI Analysis → Visualization → Dashboard → Business Insights**

## 🛠️ Tools & Technologies

* Python
* Pandas
* Matplotlib
* Excel
* OpenPyXL
* Jupyter Notebook / PyCharm

## 🧹 Data Cleaning

The dataset was cleaned using Python and Pandas.

Main cleaning steps:

* Handled missing values in Sales and Profit.
* Removed duplicate records.
* Removed extra spaces from Customer names.
* Standardized City names.
* Standardized Category names.
* Checked data types.
* Verified that no missing values remained.

## 💡 Business Insights

* Laptop generated the highest sales with **108,000**.
* Laptop contributed approximately **54.08%** of total sales.
* Cairo generated the highest city sales with **117,695**.
* Cairo contributed approximately **58.94%** of total sales.
* Electronics generated the highest category sales with **156,000**.
* Keyboard achieved the highest profit margin at **30%**.
* Total profit margin was **16.24%**.

## 🎯 Business Recommendations

1. Analyze the factors behind Laptop's high sales performance.
2. Study customer demand and purchasing behavior in Cairo.
3. Monitor products with high profit margins alongside products with high sales.
4. Evaluate product performance using Sales, Profit, Profit Margin, and Quantity rather than Sales alone.
